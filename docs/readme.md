## Usage

To use Stain in your project without downloading, import it via CDN:

    @font-face {
      font-family: "Stain";
      src: url("https://cdn.jsdelivr.net/gh/PlanetRenox/StainFont@v1/dist/Stain.otf") format("opentype");
    }

    body {
      font-family: "Stain", sans-serif;
    }
